# Ink & Ideas — Blog Platform with Comments

A beginner-friendly, responsive blog website built with HTML, CSS, and JavaScript. It runs directly in a browser—no Node.js, npm, database setup, or terminal required.

## Features
- Responsive blog landing page
- Three sample posts and category filters
- Search stories by title, author, or content
- Create and publish a post
- Open and read full posts
- Add comments to posts
- Saves new posts and comments in the browser using localStorage

## Run it on your computer
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click `index.html` to open it in your browser.

That's it! No installation required.

## Upload to GitHub
1. Sign in at https://github.com and create a new repository.
2. Open the repository page and select **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder (upload the files themselves, not the ZIP).
4. Click **Commit changes**.
5. To publish the website, open repository **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section.

## Important note
This is a front-end demo project. Posts and comments are stored only in the current browser on the current device. They are not shared with other visitors and will not sync to another device. A real multi-user blog needs a backend and database.
